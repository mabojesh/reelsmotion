# Hooks: the first 3 seconds

People decide in about a second. The first frame must already say something; never start on an empty or fading screen.

A hook has three layers that say the same thing:
1. **The line** (spoken or written): short, concrete, a little surprising.
2. **The text on screen:** the key words, big, readable without sound.
3. **The motion:** something moves in the first 0.3 s (a slam, a zoom, a stamp).

## Families to choose from
| Family | Example |
|---|---|
| Wrong belief | «كلنا منسخّن السيارة ١٠ دقايق… وهاد غلط» |
| Question / challenge | «صح ولا غلط؟ جرّب تجاوب قبل العدّ» |
| Number | «٣ أشياء ما حدا قلك ياها عن…» |
| Result first | Show the finished thing, then «هيك عملتها» |
| Mistake | «لا تعمل هالغلطة لما…» |
| Personal | «من ١٠ سنين وأنا مهندس… وهي أكتر شغلة بتنسأل» |

## Rules
- Offer three hooks from different families and recommend one.
- Keep the promise: whatever the hook says, the video pays off.
- Comment bait at the end should be easy to answer (a number, a yes/no, one word).
